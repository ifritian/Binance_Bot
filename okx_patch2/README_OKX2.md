# OKX2 — картинки в черновиках + отдельный чат для OKX Orbit

Это ДОПОЛНЕНИЕ к OKX1 (примени его сначала, если ещё не применён).

## Что нового

- **`chart_generator.py`** — водяной знак "BINANCE" на графике теперь
  можно отключить (`watermark_text=None`) и добавлять свой суффикс к
  имени файла, чтобы графики под разные площадки не перезаписывали друг
  друга.
- **`okx_orbit_generator.py`** — новая функция `generate_chart_for_post(theme)`:
  строит график по первому тикеру темы, БЕЗ водяного знака Binance.
- **`main.py`** — черновик OKX Orbit теперь всегда пытается приложить
  график; если график не построился (сетевая ошибка и т.п.) - черновик
  всё равно уходит, просто без картинки, публикация не блокируется.
- Новый тест на `generate_chart_for_post`.

Полный прогон тестов после изменений - 529 passed (те же 2 файла с
уже существовавшим до этих патчей багом раннера, не связанным с ними).

## Второй вопрос — отдельный чат для OKX-черновиков

Код уже это поддерживает "из коробки": `OKX_ORBIT_DRAFT_CHAT_ID` в
`.env` — отдельная переменная от `YOUR_USER_ID` (тот, что используется
для алертов о сделках). Значит нужно просто получить ВТОРОЙ `chat_id` и
вписать его именно туда. Проще всего — через отдельную Telegram-группу:

1. В Telegram создай новую группу (например, назови "OKX Orbit черновики") -
   можно только с собой, без других участников.
2. Добавь в эту группу своего бота (того же, чей токен уже в `.env`) как
   обычного участника.
3. Напиши в этой группе любое сообщение, например "привет".
4. Открой в браузере (замени `ТВОЙ_ТОКЕН` на реальный):
   ```
   https://api.telegram.org/botТВОЙ_ТОКЕН/getUpdates
   ```
5. Найди в ответе блок с этой группой - `"chat":{"id":-100123456789,...`
   (у групп `id` ОТРИЦАТЕЛЬНЫЙ, часто длинный, начинается с `-100`) -
   это и есть отдельный `chat_id` для OKX-черновиков.
6. В `.env` пропиши именно это значение:
   ```
   OKX_ORBIT_DRAFT_CHAT_ID=-100123456789
   ```
   (а `YOUR_USER_ID`, если уже настроен под алерты о сделках, оставь
   как есть - он используется только для алертов, а не для черновиков).

После перезапуска бота черновики OKX Orbit будут приходить именно в эту
отдельную группу, а уведомления о сделках - как раньше, тебе в личку.
